# Task 6: Paradigm Comparison, Marking Scheme

Companion to `BRIEF_T6.md` | Module code PRG1

20 marks total, 10% of the module assignment: 10 for the guided comparison, 10 for the written reflection. No code is submitted for this task.

## Part 1: Guided comparison, 10 marks

| Marks | What it shows |
|---|---|
| 8-10 | All four answers accurate and grounded in the actual code (right function, method, or line of reasoning). |
| 4-7 | Some answers correct but generic (e.g. "OOP uses a class") rather than referencing the code. |
| 0-3 | Answers mostly inaccurate or missing. |

## Part 2: Written reflection, 10 marks

Questions: 1) a genuine OOP advantage, 2) a genuine procedural advantage, 3) which version would be easier to extend to more item types and branches, and why. There is no single correct answer to question 3; a strong answer can favour either approach if the reasoning is genuine and specific.

| Marks | What it shows |
|---|---|
| 8-10 | All three answers specific and well-reasoned, grounded in this program rather than paradigms in general. |
| 4-7 | Some genuine points, but underdeveloped, or reasoning that does not go beyond a bare preference. |
| 0-3 | Generic claims about paradigms in general (e.g. "OOP is always better") without engaging with this program. |
