# Task 6: Paradigm Comparison

Worth 10% of the module assignment | Individual work | Module code PRG1

## What you're doing

`PRG1_Task6_Procedural.py` and `PRG1_Task6_OOP.py` are two complete, working programs that solve exactly the same problem: tracking a small library's books, and which ones are checked out. Both produce identical output when run. The first is written procedurally, using functions and a list of dictionaries. The second is written using object-oriented programming, with a `Book` class and a `Library` class.

Your job is to read both versions carefully, then compare how each one solves the same problem. You are not asked to change or submit either code file: this task is assessed entirely on your written comparison.

## Before you start

- Read both files end to end. Run them both if it helps; they produce identical output.
- Where the guided questions ask you to trace something, follow the actual flow of execution through the code, line by line, rather than describing it from memory of how you think it should work.

## Guided comparison

Complete both columns for each question, in your own words, in `ANSWERS_T6.md`.

1. Where is the data for a single book stored?
2. How is "check out a book" implemented? Name the function or method, and what it belongs to.
3. Trace what happens if you try to check out a book that is already checked out. Which lines handle that case?
4. If you needed to add a new piece of information to every book, for example a genre, what exactly would you need to change?

## Written reflection

Answer all three in `ANSWERS_T6.md`. Each answer should be a genuine, specific point about this particular problem, not a general statement about programming paradigms. "OOP is more organised" is not a specific enough answer on its own; explain what about this program specifically supports the point you are making.

1. Describe one genuine advantage of the object-oriented version over the procedural version, for this specific problem.
2. Describe one genuine advantage of the procedural version over the object-oriented version, for this specific problem.
3. If this library tracker needed to grow to handle thousands of books, multiple branches, and several kinds of item beyond books (for example, DVDs and equipment), which version would be easier to extend, and why?
