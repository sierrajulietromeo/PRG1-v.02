# Task 1: Construct Identification

Worth 5% of the module assignment | Individual work | Module code PRG1

## What you're doing

The file `PRG1_Task1_ConstructID_starter.py` contains a complete, working program: a shift pay calculator. It already runs correctly. You are not writing or changing any code for this task.

Your job is to read the program carefully, then identify and explain the programming constructs it uses, using the table below. This is an individual task: complete it in your own words, even if you discussed the code with a partner informally beforehand.

## Before you start

- Open `PRG1_Task1_ConstructID_starter.py` and read it end to end before filling anything in.
- You may run the program if it helps you understand what it does, but running it is not required.
- Quote directly from the code where the table asks you to. Use your own words for the explanations.

## Identification table

Find each construct below in the code, then answer in `ANSWERS_T1.md`.

| Construct | Find it in the code |
