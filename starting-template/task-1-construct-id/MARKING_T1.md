# Task 1: Construct Identification, Marking Scheme

Companion to `BRIEF_T1.md` | Module code PRG1

20 marks total, 5% of the module assignment: 10 for identification, 10 for explanation quality.

## Part 1: Identification, 10 marks

| Marks | What it shows |
|---|---|
| 8-10 | All or nearly all 10 constructs correctly identified. |
| 4-7 | About half correct; some rows wrong, missing, or the same example used twice. |
| 0-3 | Most rows missing or incorrect. |

## Part 2: Explanation quality, 10 marks

| Marks | What it shows |
|---|---|
| 8-10 | Specific, accurate explanations across all 5 areas below. |
| 4-7 | Some areas strong, others generic, missing, or just restate the code. |
| 0-3 | Explanations mostly missing or restate the code without saying why. |

A strong explanation covers:

| Area | What a strong answer shows |
|---|---|
| Constant vs variable | Why it's a fixed policy value, not data that varies per shift. |
| Parameters and return | Both the parameters and the return value, and how they relate. |
| Call sequence (flow) | Correct order, plus what each function is responsible for. |
| Expressions | What the expression calculates and why. |
| Formatted output | Why `:.2f` is used (two decimal places for currency). |
