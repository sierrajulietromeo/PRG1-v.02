# PRG1: Computer Programming, Assignment Repo

Welcome. This repository is where you will build up the evidence for your PRG1 assignment over the course of the module: code, written answers, and marking schemes for each task, all in one place.

## How this repo works

You are not given every task at once. Tasks are released one at a time as the module progresses, each as a new folder added to this repo (you will be told how and when each one arrives). By the end of the module, this repo will contain all seven tasks, each in its own numbered folder, plus your AI use reflection.

Each task folder contains three files:

- `BRIEF_TN.md`, the task instructions.
- `MARKING_TN.md`, the marking scheme for that task, so you know exactly what is being assessed before you start.
- `ANSWERS_TN.md`, where you write your answers. Most task folders also include starter code and, where relevant, a test file.

Right now, you only have Task 1. Its folder is `task-1-construct-id/`.

## The assignment as a whole

One assignment, seven tasks, worth 100% of the module mark. A raw score of 40% or more across the whole assignment is a pass. The table below shows what is coming and how much each task is worth; task briefs are released in order, so you will get full details on each one when it arrives, not before.

| Task | Title | Weighting |
|---|---|---|
| 1 | Construct Identification | 5% |
| 2 | Debugging, Part A | 10% |
| 3 | Applied Implementation | 15% |
| 4 | Test-Driven Completion | 15% |
| 5 | Debugging, Part B | 10% |
| 6 | Paradigm Comparison | 10% |
| 7 | Open Research Task and Oral Walkthrough | 35% (20% + 15%) |

## AI use reflection

`AI_USE_REFLECTION.md` is already in this repo, even though you will not complete it until the very end of the module. It is a single, short, mandatory reflection on your AI tool use across the whole assignment. You do not need to log or track anything task by task; just look back and fill it in once, at the end. It is not marked and does not affect your grade on any task, but it is a required part of your submission.

## A note on AI tools

Using an AI tool does not affect your mark, on any task, unless a task's own brief says otherwise (Task 7 is the one exception, where your use of AI is part of what the written note and oral walkthrough assess). Each `MARKING_TN.md` tells you exactly what is being marked; read it before you start the task, not just after.
