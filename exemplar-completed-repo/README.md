# PRG1 Exemplar Submission (Markers Only)

This is a fabricated, complete PRG1 assignment repo, written to show what a realistic, average, borderline pass-to-merit submission from an 18-year-old first-year apprentice looks like across all seven tasks. It is for marking calibration by the teaching team.

**Do not give this to students.** It is not in `starting-template/` or `release-packages/`, and it should not be added to Classroom 50 or any student-facing repo. Releasing it, especially before or during a live run of the module, would hand out working answers to several tasks, in particular the two debugging tasks and Task 7's open research problem.

## What "average" means here

Every task's code has been run against its real test suite (where one exists) and passes. The written answers are deliberately not polished: they are mostly correct, reasonably clear, and specific to the code, but with the kind of minor gaps, casual phrasing, and occasional restated-rather-than-fully-explained points typical of a genuine mid-cohort submission, not a model distinction-level answer. Some tasks are stronger than others, as they would be for a real student: for example Task 7's written note is fairly thorough, while Task 1's explanation section deliberately includes one thinner, more generic point (the formatted-output explanation), consistent with the "8-10 vs 4-7" band boundary in that task's marking scheme.

Use this to sanity-check where you would actually draw the Pass/Merit line in practice, not as a fixed answer key; a real submission at this level will vary in exactly which parts are strong or weak.

## Contents

Each `task-N.../` folder contains the completed code (where applicable) and a filled-in `ANSWERS_TN.md`. `AI_USE_REFLECTION.md` at the top level is a filled-in example of the mandatory end-of-module reflection. Marking schemes are not duplicated here; use the copies in `starting-template/` and `release-packages/`.
