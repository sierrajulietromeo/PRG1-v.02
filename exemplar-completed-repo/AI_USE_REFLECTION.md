# End-of-Module AI Use Reflection

## 1. How did you use AI tools across the assignment, if at all?

> I used it mostly on Task 7, since that one didn't have a starter file to work from, and a little bit on Tasks 3 and 4 when I got stuck on an error message I didn't understand. I didn't use it at all on the debugging tasks, Task 2 and Task 5; I wanted to find those faults myself since that felt like the actual point of those tasks. Mostly I used it to explain things or help me understand an error, not to write whole chunks of code for me, except on Task 7 where I did ask it directly for help with the midnight wraparound logic.

## 2. How did you check whether what it gave you was actually correct?

> For the error message help on Tasks 3 and 4, I just tried the fix it suggested and reran the tests to see if they passed, so that was quick to check either way. For Task 7's time wraparound suggestion, I tested it myself with a few made-up times close to midnight to check the output actually made sense, rather than just assuming it was right because it sounded confident.

## 3. What did you learn from using it, or from checking its output?

> I learned that AI tools are pretty reliable for explaining what an error message actually means, which saved me a lot of time compared to searching for it myself. I also noticed that when I asked it more general questions, like how to compare two dictionaries, it sometimes gave me a more complicated answer than what I actually needed for the task, so I think it's easy to end up using something more advanced than necessary if you copy what it gives you without thinking about whether it actually fits.

## 4. Where was it useful, and where was it not, or where did you choose not to use it?

> It wasn't useful, or rather I chose not to use it, on the debugging tasks, because I wanted to work through the logic myself; I think just asking an AI to find the bug would have meant I didn't actually learn how to spot that kind of mistake on my own. Looking back, I probably could have tried a bit harder to work out the midnight wraparound logic on Task 7 by myself before asking, since once I saw the modulo approach it actually made sense pretty quickly.
